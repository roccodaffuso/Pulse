# Pulse Vitals

Official support and privacy resources for Pulse Vitals.

Pulse Vitals is a local-first Apple Health companion for viewing heart rate,
blood oxygen, steps, sleep, widgets, and Apple Watch complications at a glance.

## Download

[Download Pulse Vitals on the App Store](https://apps.apple.com/app/id6772466715)

## Support

Search the existing [support issues](https://github.com/roccodaffuso/Pulse/issues)
or open a new issue if you need help.

Issues are public. Do not include health values, personal identifiers, or
screenshots that expose sensitive information.

## Privacy

Read the [Pulse Privacy Policy](docs/PRIVACY_POLICY.md).

## Repository Scope

This repository contains public support and privacy resources. It does not
contain the Pulse application source code.
